如何新增連結
在這個 HTML 檔案最上方的 <script id="portal-data"> JSON 陣列中， 新增一個物件即可。儲存後推到 GitHub，Portal 立即更新。
// 複製貼到 JSON 陣列最後（記得前一個物件結尾加逗號） { "id": "new-page-id", // 唯一英文 ID "name": "我的新頁面", "repo": "repo-name", // GitHub repo 名 "category": "retcp", // retcp|oc|market|system|other "status": "live", // live|pending|unknown "icon": "🔧", "desc": "頁面用途的一到兩句說明。", "tags": ["標籤1", "標籤2"], "links": [ { "label": "主頁", "url": "https://mac2good909777-commits.github.io/repo-name/", "isPrimary": true }, { "label": "Repo", "url": "https://github.com/mac2good909777-commits/repo-name", "isPrimary": false } ] }
💡 部署建議：把這個 index.html 推到 mac2good909777-commits/public repo 的根目錄， 即可從 https://mac2good909777-commits.github.io/ 直接存取，作為你的 GitHub 首頁入口。

或推到 system-architecture repo 的 /hub/ 子目錄，保持現有架構不變。
