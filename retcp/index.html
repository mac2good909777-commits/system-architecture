設定 GitHub Token（只需一次，存在本機瀏覽器）

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access：Only select repositories → retcp
  3. Permissions → Repository permissions → Issues：Read-only（Metadata 會自動帶入）
  4. 產生後貼到下面，按儲存
Token 僅存於此瀏覽器 localStorage，用於唯讀存取 private repo 的 issues。面板本身不含任何資料，沒有 token 的訪客看不到內容。
