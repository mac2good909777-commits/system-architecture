二、土地謄本欄位全解析

2.1 土地標示部（11個欄位）

#欄位說明查驗重點
1總公告現值面積 × 公告土地現值估算底價基準
2總公告地價面積 × 公告地價地價稅計算基礎
3登記日期本次登記的日期（非買賣日期）搭配登記原因解讀
4登記原因本次謄本登記的原因見登記原因對照表
5面積土地面積（㎡/坪）核對地籍圖量尺是否吻合
6使用分區都市土地 空白；非都市填入（特農區等）兩欄空白 ≠ 無限制！
7使用地類別都市土地 空白；非都市填入（農牧/甲建/丁建等）丁種建築用地可建廠
8公告土地現值年份＋元/㎡（萬/坪）土增稅計算基礎
9公告地價年份＋元/㎡地價稅計算基礎
10地上建物建號該土地上的合法登記建物空白不代表無建物（舊屋/未登記）
11其他登記事項分割自、重測前地段地號、合併等歷史追溯前地號的關鍵欄位

2.2 土地所有權部（12個欄位）

#欄位說明查驗重點
1共N位所有權人土地所有人數>1人 = 需確認全體同意出售
2登記次序本次登記的順序號非0001 = 有更早歷史，可調舊謄本
3登記日期本次所有權登記日期—
4登記原因取得原因（買賣/贈與/交換/繼承等）—
5原因發生日期契約或事實發生日期比登記日期早，是實際交易日
6所有權人姓名（遮蔽）+ 統一編號（部分遮蔽）L開頭=自然人；B/C等=法人
7地址所有人戶籍地址與建物門牌相同=自住；不同=非自住
8權利範圍持分比例1/1=全部；1/2=共有各半
9權狀字號土地所有權狀字號—
10相關他項權利登記次序對應到他項權利部的登記有值 = 有抵押或其他他項
11當期申報地價所有人自報地價（通常 < 公告地價）—
12前次移轉現值或原規定地價上次移轉時的公告現值極低=農地傳承；時間久=土增稅重
附歷次取得權利範圍若曾分批取得，列出每次比例Type H：分三批取得合計全部

2.3 土地他項權利部（17個欄位）

#欄位說明查驗重點
1登記次序抵押次序（0001最優先）0002以上 = 有二胎，高資金壓力
2收件年期申請登記年度—
3登記日期正式登記日期—
4權利種類一般抵押/最高限額抵押見抵押類型對照表
5字號證明書字號同字號 = 同一筆抵押同時擔保土地+建物
6登記原因設定/塗銷/擔保物增加擔保物增加 = 建物完工後追加
7權利人銀行/法人/自然人自然人 = 私人借貸，最高資金壓力
8債權額比例全部1/1 or 持分—
9擔保債權總金額設定的最高限額或確定金額通常 = 成交價 × 7~8成
10擔保債權確定期日最高限額抵押才有≤2年內到期 = 急迫還款壓力
11清償日期依各契約約定—
12~14利息/違約金依各契約約定—
15權利標的所有權/地上權—
16設定權利範圍抵押的持分範圍—
17共同擔保建號/地號同一筆抵押擔保的其他不動產多筆=投資客打包；跨行=重複擔保風險

三、建物謄本欄位全解析

3.1 建物標示部

#欄位說明查驗重點
1所有面積（總）主建物+附屬建物+共有部分持分面積合計—
2登記日期本次建物登記日期—
3登記原因第一次登記/門牌整編/基地號變更等門牌整編=非新建，僅更新登記
4建物門牌建物地址—
5建物坐落地號建物所在的土地地號需與土地謄本地號核對
6主要用途住家用/廠房/辦公室等廠房可列多種用途
7主要建材RC/加強磚造/鋼骨等並列=混合構造（老舊常見）
8層數地上幾層—
9總面積主建物各層次面積合計—
10層次面積逐層登記（一層/二層/夾層/B1/騎樓/屋突）2F>1F=出挑；夾層=合法登記
11建築完成日期使照發照日期（民國年）屋齡計算起點
12共有部分建號/持分公設持分無=透天；有=大樓/公寓
13附屬建物陽台/雨遮/平台/露台廠房有平台；舊公寓無
14使用執照字號建物合法性來源與建照查詢系統核對
15其他登記事項重測前建號、建照字號等—

3.2 建物所有權部

欄位說明查驗重點
登記次序0001=第一次；0002=轉手後—
登記原因第一次登記/買賣/交換/贈與等—
所有權人姓名+統編是否與土地所有人相同
權利範圍全部1/1 or 持分—
相關他項權利登記次序對應建物他項權利部—

3.3 建物他項權利部

結構同土地他項權利部，需核對：
  • 共同擔保建號/地號 與土地謄本一致
  • 字號與土地他項相同 = 同一筆貸款

六、都市土地 vs 非都市土地 謄本識別

6.1 有填寫 → 直接判斷

謄本欄位代表範例
使用分區＋使用地類別 均有值非都市土地，已編定特定農業區／農牧用地

6.2 兩欄均空白 → 兩種可能

⚠️ 空白 ≠ 一定是都市土地！需進一步確認
情形說明確認方式
情形1
都市土地		 都市計畫發布後，計畫內土地依都市計畫法重新給予身分，不再登載於謄本 向 區公所 或 都發局 申請使用分區證明
情形2
非都市（未編定）		 土地屬非都市範圍，但尚未完成使用分區及類別的編定 向 土地所轄地政事務所 申請辦理編定；完成後謄本即有明確記載

判斷都市土地非都市土地

七、各類型特殊識別要點

A 電梯大樓

  • 土地持分按比例均分
  • 共有部分 2 個以上（管理室/機房/停車場）
  • 1戶1建號

B 獨棟廠房透天

  • 土地全部持有（1/1）
  • 無共有部分
  • 1棟1戶1使照

C 複合廠房

  • 同一地號多個建號（一地多建物）
  • 各建號各自有使照
  • 面積驗算：地號面積需與各棟建照基地面積核對

D 地上權廠房

  • 無土地所有權，只有地上權
  • 土地所有人（多為國有或港務局等）另行設定
  • 他項權利部可能有地上權登記

E 舊式公寓 1F

  • 1F持分遠高於上層（含騎樓+B1）→ 1F持83%
  • 層次含「騎樓」→ 1F商業用
  • 擔保物增加登記 → 先蓋後貸
  • 共同擔保建號少於地上建號總數 → 確認所有權分散

F 非都市廠房

  • 謄本使用分區：特定農業區 + 使用地類別：丁種建築用地
  • 最高限額抵押確定期日 30 年
  • 地籍圖重測前後地段名稱+地號均不同

G1 社區透天（整批）

  • 建照 1 筆使照 = 多棟（社區規模）
  • 土地分割後各戶各自 1/1 持有
  • 無共有部分
  • 投資客可能持多戶「打包」最高限額抵押
  • 跨行重複擔保風險：同一建號被兩不同銀行的不同借款人共同擔保

G2 連棟透天（各自建照）

  • 各棟獨立申請建照（1幢1戶）
  • 基地地號 1 筆（各棟獨立）
  • 「共同壁」在建照備註中明確記載
  • 面積遞增 = 有騎樓，上層向前出挑

H 高矮混合社區透天

  • 同一使照涵蓋高層大樓+低層透天
  • 有 3 個共有部分（公設比 26.2%）
  • 逕為地目變更（農→建）
  • 跨使用分區（二種+三種住宅區）
  • 未保存登記並存
  • 土地三批取得

I-a 都市農業區素地

  • 謄本無分區記載（須查都市計畫圖）
  • 逕為分割登記（政府主動）
  • 夫妻共有識別：地址相同 + 配偶贈與
  • 農地移轉需農業使用承諾書

I-b 都市農業區大地塊

  • 地目等則調整（057年）= 最古老登記類型
  • 前次移轉現值極低（064年：45.4元/㎡）= 農地世代傳承
  • 登記次序非0001 → 有更早移轉歷史
  • 大面積完整地塊（2,144坪）

J 同地號雙建照舊透天

  • 套匯圖顯示兩個不同年代建照號（075建＋080建）
  • 系統顯示「含未保存登記」
  • 謄本標示部地上建物建號欄空白（舊屋常見）
  • 分割轉載 = 因地號分割，資料轉入，非新買賣

K 老舊加強磚造透天

  • 建物面積 > 土地面積（2F出挑，建蔽率只算1F）
  • 交換登記（以不動產換不動產）
  • 集體建照（059年，15筆地號共同申請）
  • 加強磚造+RC並列 = 1950-70年代混合構造
  • 門牌整編 = 老建物門牌重整後更新登記
  • 高LTV抵押（1,000萬/估算成交價1,042~1,190萬）

  • 首碼與不動產所在縣市不同 → 非本地持有，注意是否為人頭或投資佈局
  • 法人（公司）統一編號為 8 位數字，無字母首碼，直接可辨別
  • 謄本僅顯示部分遮蔽統編，通常可見首碼字母
注意： 台北縣升格為新北市後代碼仍為 F；桃園縣升格桃園市後代碼仍為 H；台中縣市合併後舊台中縣代碼 L 仍存在於舊戶籍身分證中。

9.3 建照 vs 謄本面積差異正常範圍

  • 謄本面積 > 建照面積：因丈量方式不同（謄本含外牆厚度），差值 1–3㎡/層屬正常
  • 謄本面積 >> 建照面積：需查是否有違建增建
  • 建物坐落地號 ≠ 建照基地地號：查是否有地籍重測合併或分割

十一、謄本資料上傳規則（RETCP v1）

上傳單位：以標的為單位（同一物件的資料一起上傳）

資料優先順序

  1. 土地謄本（土地標示部 + 所有權部 + 他項權利部）
  2. 建物謄本（建物標示部 + 所有權部 + 他項權利部）
  3. 建照（使照基本資料 + 樓層概要）
  4. 套匯圖（建物輪廓，核查違建/越界）

重複處理規則

  • 同使照號碼 / 同地號+地段 = 同一筆
  • 重複上傳同類資料 → 自動合併，略過重複分析
